# Todo

Task manager with categories, priorities, a Shamsi due-date calendar, search and filters, collapsible task details, swipe-to-edit / swipe-to-delete on phones, and a persisted dark theme.

اپ مدیریت کارها با دسته‌بندی، اولویت، تقویم شمسی و حذف و ویرایش با سوایپ.

**Live:** https://todo-sigma-one.vercel.app/

## Stack
React · shadcn/ui (Radix) · Zustand (persisted) · framer-motion · react-day-picker · Tailwind CSS

## Run
```bash
npm install
npm run dev
```
